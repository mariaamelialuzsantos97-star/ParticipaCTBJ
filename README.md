# ParticipaCTBJ

> Plataforma para registrar e consultar a participação dos estudantes em atividades escolares e extracurriculares do Colégio Técnico de Bom Jesus (CTBJ).

## 1. Sobre o projeto

O ParticipaCTBJ é um sistema desenvolvido para facilitar o registro e a consulta da participação dos estudantes em atividades realizadas pela escola.

A plataforma permitirá cadastrar estudantes, cadastrar atividades e registrar quais estudantes participaram de cada atividade.

## 2. Problema identificado

Os registros de participação dos estudantes podem ficar espalhados em listas, documentos ou outros meios.

Isso pode dificultar a organização e a consulta dessas informações.

Por isso, o ParticipaCTBJ busca reunir esses registros em um único sistema.

## 3. Solução proposta

O ParticipaCTBJ será uma plataforma onde será possível:

- Cadastrar estudantes;
- Cadastrar atividades;
- Registrar participantes;
- Consultar atividades;
- Consultar participantes;
- Consultar o histórico de participação dos estudantes.

## 4. Objetivos

### 4.1 Objetivo geral

Desenvolver um sistema para registrar, organizar e consultar a participação dos estudantes em atividades escolares e extracurriculares.

### 4.2 Objetivos específicos

- Cadastrar estudantes;
- Cadastrar atividades;
- Registrar a participação dos estudantes;
- Organizar as atividades por categorias;
- Permitir a consulta das atividades;
- Permitir a consulta do histórico de participação.

## 5. Público-alvo

O ParticipaCTBJ será destinado a:

- Estudantes do CTBJ;
- Professores do CTBJ;
- Responsáveis pela organização escolar.

## 6. Principais funcionalidades

### Para estudantes

- Consultar suas participações;
- Consultar seu histórico de atividades.

### Para professores

- Cadastrar atividades;
- Registrar estudantes participantes;
- Consultar os participantes das atividades.

### Para responsáveis pela organização escolar

- Cadastrar estudantes;
- Cadastrar atividades;
- Gerenciar os registros de participação;
- Consultar as informações cadastradas.

## 7. Tipos de atividades

O sistema poderá registrar atividades como:

- Projetos;
- Feiras;
- Olimpíadas;
- Apresentações;
- Competições;
- Oficinas;
- Eventos escolares;
- Outras atividades extracurriculares.

## 8. Histórico de participação

O sistema permitirá que os estudantes consultem as atividades das quais participaram.

Essa funcionalidade ajudará a manter um registro organizado das atividades realizadas pelos estudantes.

## 9. Segurança

Somente usuários autorizados poderão alterar informações sobre estudantes, atividades e participações.

Os dados dos estudantes deverão ser protegidos e acessíveis somente por usuários autorizados.

## 10. Tecnologias

As tecnologias utilizadas no desenvolvimento do sistema serão definidas durante as próximas etapas do projeto.

## 11. Benefícios esperados

Com o desenvolvimento do ParticipaCTBJ, espera-se:

- Facilitar o registro das participações;
- Melhorar a organização das informações;
- Facilitar a consulta das atividades;
- Manter o histórico de participação dos estudantes;
- Centralizar as informações em um único sistema.
